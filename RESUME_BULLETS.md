# Resume Bullets — Singapore Healthcare Analytics Project

- Engineered a reproducible Python (pandas) pipeline to clean and reconcile three Singapore government healthcare datasets (2015–2025) with inconsistent wide/hierarchical formats, validating 741 admissions category-months against source totals and transparently documenting a genuine 68-bed discrepancy between national and regional capacity sources rather than silently correcting it.

- Built a two-page Power BI dashboard (20 DAX measures, custom Year-dimension data model) backed by DuckDB SQL, analyzing a decade of Singapore hospital admissions and bed-capacity trends; surfaced that Public Acute Hospital admissions grew 44.4% versus 32.7% bed-capacity growth from 2015–2025 (indexed), without conflating the result with an occupancy metric.

- Applied exploratory data analysis and SQL (CTEs, window functions) to Singapore healthcare utilisation data, quantifying that Community Hospital admissions grew 183.3% versus 31.7% for Acute Hospitals (2015–2025) and that hospital bed capacity is 52.5% concentrated in the Central planning region.
